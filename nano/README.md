# Arduino Nano Firmware

## Final firmware

The confirmed final Arduino Nano sketch is:

`Nanov12/Nanov12.ino`

Open this sketch in the Arduino IDE and select the correct Arduino Nano board and processor option for the physical board.

## Historical versions

The `versions/` directory preserves the earlier sketches:

- `Nano/Nano.ino`
- `Nanov1/Nanov1.ino` through `Nanov11/Nanov11.ino`

These files are retained for development history. They should not be treated as the final firmware.

## Validation status

Nano v12 is designated as the final project sketch by the project owner. Compilation and hardware operation must be verified separately before deployment.
